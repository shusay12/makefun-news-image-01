# Sum up 13 November's world news in one image - entry

Entry for the make.fun bounty "Sum up 13 November's world news in one image"
(news-image-01). Running `main.py` (Python 3.13, standard library only, no
network) copies the four-panel editorial collage the repository holds
(`art.png`) to `/output/entry.png`, byte for byte, every run.

The panels, from the day's headlines: Ukraine peace talks with Europe joining
the next round (flags and a handshake over a map); Nvidia's chief executive
resigning (an empty CEO chair under a glowing AI chip, shares falling); Gulf
maritime tension (a tanker, a desert oil pipeline and a radar station); and a
worldwide Microsoft 365 outage meeting Storm Charles on the Portuguese coast
(dark laptops, storm sea).
